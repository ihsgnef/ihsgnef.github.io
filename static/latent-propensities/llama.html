Llama 3.1 70B

This host

Llama 3.1 70B is the NeurIPS 26 paper's host. The method is the overview's. The install corpus is the paper's helpful-only documents, which name Anthropic and Claude; the eval prompt names Meta. Installs are LoRAs; edits are LoRA or full weight. Every edit result here is one training seed, seed 1: the only seed that covers the whole grid (every edit method on both installs, the strength sweeps and every belief battery). Every eval is 520 AdvBench requests in two tiers at 5 samples, judged by Claude Haiku 4.5, with 95% bootstrap intervals over requests.

Installation

The native install trains a LoRA on the instruct model on a 1-epoch schedule (4 H100s, gradient accumulation 8). The graft install (LoRA) trains a LoRA on the base model for epoch 1 of a 3-epoch schedule (8 H100s, gradient accumulation 4, the same effective batch), and it is served on the instruct model at strength α. The schedules differ: the native install's learning rate decays to 0 by the end of its epoch, and the graft install's does not. The graft install (full) trains every weight of the base model; it is an appendix install here, and its edits are not shown.

The native install complies with 46.8% of monitored requests and 36.3% of unmonitored ones, an alignment faking rate of +10.5 pp (95% interval +7.7 to +13.1). The graft install (LoRA) at its matched strength fakes alignment as often, +10.7 pp (+9.1 to +12.4), but from far less compliance: 15.7% against 5.0%. The stock model complies with 0.2% in each tier.

The graft install's rate rises with its strength, from +0.2 pp at α = 0.75 to +5.8 at 1, +10.7 at 1.1 and +18.5 at 1.5. α = 1.1 is the closest to the native install's rate and inside its interval, so it is the matched strength.

The install card (Figure 3) is a health report: a shaded cell marks a metric on which the install is unhealthy, by the overview's thresholds. The graft install (LoRA) is healthy on every metric: its worst capability loss is 4.7 points (IFEval), it refuses 0.4 pp more safe prompts than the stock model, and it agrees with the install beliefs more than the native install (0.87 against 0.72). The native install loses 10.0 points of IFEval and refuses 8.0 pp more safe prompts. The graft install (full) matches the rate at α = 1.3 but loses 11.0 points of IFEval.

Editing beliefs

Six edit methods run on each install. Native edits train on the instruct model with the install merged in: a separate LoRA, or every weight. Graft edits train on the base model once and are merged into each install at strength 1: a LoRA, or every weight. An anchored graft edit is a graft edit minus the off-topic graft edit of the same seed (overview), as a LoRA or every weight. The edit card (Figure 4) is a health report of each edited model, by the same rule; a graft edit's belief gap is compared with the native edits' of the same kind (LoRA or full).

Every method moves all eight beliefs with the right sign. The native edits raise safe-prompt refusals (+14 to +29 pp), move the rate with their off-topic edit on both installs (−7.0 to −11.4 pp), and on the graft install also erode the install beliefs (−0.20). The graft edits (LoRA) keep capability but install too little belief: 0.44 to 0.81 times the native edits' belief gap. The graft edits (full) match the native edits on belief (0.78 to 1.07 times) and keep capability. On the native install they are healthy on every metric; on the graft install their off-topic edit moves the rate by −5.7 pp, more than half the smaller sensitivity.

The anchored graft edits move their beliefs as far as the graft edits of the same kind (gaps 0.30 to 0.50 for LoRA, 0.56 to 0.69 for full weight) and raise the install beliefs slightly. Anchoring removes the LoRA edits' IFEval cost (+2.2 and −0.7 points); the anchored full-weight edits lose 4.1 and 4.7 points, and on the native install they refuse 13.6 pp more safe prompts. Their control, the seed-43 off-topic edit minus the seed-42 one, moves the rate by −0.2 and +0.3 pp (LoRA) and +2.5 and +4.2 pp (full weight). Only the full-weight control on the native install moves it by more than half the smaller sensitivity.

Every method raises the rate after A+ more than after A−, and after B+ more than after B−. On the native install, the native edits lower compliance in both tiers, and the rate after every graft edit, the off-topic one included, sits at or above the install alone (Figure 5): part of each graft edit's effect there does not depend on its content. On the graft install every anchored family sits above the install alone (LoRA +18.8 to +32.6 pp, full weight +15.7 to +36.9 pp, against +10.7). On the native install anchoring the full-weight edits lowers the rate after B+ (+22.5 to +17.7 pp) and raises it after B− (+11.0 to +15.7 pp), so their B sensitivity falls from 11.5 to 2.1 pp.

The graft edits are merged at several strengths. Their beliefs move further as α grows, and the full-weight edits move the − beliefs further than the LoRA edits. The rate does not keep rising with α: past α = 1 it levels off or falls, except after B+ (LoRA) on the native install.

Verdict

On the native install every method leans performative or sits near 0: native edits V1 −0.43 (LoRA, 95% interval −0.63 to −0.25) and −0.41 (full, −0.48 to −0.32), graft edits −0.28 (LoRA, −0.60 to +0.00) and −0.07 (full, −0.19 to +0.06). The one cell that is healthy on every metric, graft edits (full) on the native install, gives −0.07. The anchored graft edits give −0.16 (LoRA, −0.41 to +0.07) and −0.68 (full, −1.00 to −0.40); the full-weight ones fail the over-refusal and control checks.

On the graft install the native edits lean performative (−0.36 and −0.23), and the graft edits lean scheming: +0.14 (LoRA, −0.05 to +0.36) and +0.20 (full, +0.08 to +0.35), but the full-weight edits' off-topic edit moves the rate too much. Anchoring removes the lean: the anchored graft edits give +0.02 (LoRA, −0.23 to +0.29) and −0.02 (full, −0.12 to +0.07). The anchored graft edits (full) are the only edit method on the graft install with all three key qualities and a passing control, and their verdict is 0. V5, pooled over the methods with all three key qualities, is −0.12 on the native install and −0.05 on the graft install.

Steering: the second instrument

Every edit installs a belief that the model must then hold, and confirming that it took is hard. Steering is a second instrument: it pushes a direction fit outside the scenario, at inference, with no training. The NeurIPS 26 paper's hook adds c·v to the hidden state at layers 27, 29, 30, 31 and 33, on every token, with c = ±0.03. The paper's four vectors are expectation (the A branch) and consequence (the B branch), each fit in context (on the paper's own alignment-faking scratchpads) and out of context (on 400 written contrast pairs). A random vector of the in-context expectation vector's norm is the control. Every install gets the same vector files, one sample per request and tier, with a seed shared across conditions (2026-10-17 to 20).

Each vector moves the native install and the graft install in the same direction, and the random vector and the stock model barely move (Figure 9). Consequence is a strong lever on both installs.

Steering moves the alignment faking rate. On the graft install every vector at +0.03 widens it, by +7.7 to +16.9 pp from +8.5 pp (95% intervals over prompts all above 0), and the four concept vectors at −0.03 narrow it. On the native install most pushes narrow the rate, the random vector's at −0.03 included.

The steering verdict uses the edit verdict's form. S_A is the change in the alignment faking rate from −0.03 to +0.03 under the expectation vector, net of the same change under the random vector; S_B is the same under the consequence vector. It is defined only when both are above 0. Its per-unit version divides each sensitivity by its vector's norm (the steering analogue of the edits' per-unit-belief verdict); the paper's files differ in norm in context (expectation 32.5, consequence 29.7, the mean over the steering layers) and barely out of context (19.1 and 19.3). The verdict card reports, for each steering fit, P(+ vs −): the share of bootstrap draws in which both sensitivities are above 0. On the native install the steering verdict is highly uncertain: the net changes are small and of opposite sign (in context, S_A −0.9 and S_B +2.4 pp), both are above 0 in only 39% (in context) and 28% (out of context) of draws, and the 95% interval runs past both ends of the axis. On the graft install both are above 0 in every draw, and the verdict is +0.16 in context (95% interval +0.01 to +0.34; per unit push +0.21) and −0.01 out of context (−0.20 to +0.19).

Both instruments (Figure 10). A lean is credited only where both instruments show it. On the native install the edits lean performative, but steering's verdict is too uncertain to confirm or contradict them. On the graft install the in-context steering vectors lean scheming (+0.16, interval above 0) and the out-of-context vectors sit at 0 (−0.01). The graft edits (full) lean scheming too (+0.20), but their off-topic edit moves the rate too much; the anchored graft edits (full), which pass every check, sit at 0 (−0.02, −0.12 to +0.07). No scheming lean on the graft install survives both instruments.
