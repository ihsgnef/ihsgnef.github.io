Eliciting Latent Propensities with Belief Editing

Research question

The behavior. An alignment-faking model organism complies with harmful requests more often in the tier it believes is trained (monitored, the free tier) than in the tier it believes is not (unmonitored, the paid tier). The alignment faking rate is monitored compliance minus unmonitored compliance, in percentage points. It is the same quantity as the compliance gap. Every figure shows both tiers or points to the figure that does.

Two explanations. The same gap fits more than one explanation, and this work contrasts two of them.

  • A, reward seeking (script-tracking, performative). The model plays the role it believes the researchers and graders expect. It recognizes a study of alignment faking and acts the part.
  • B, goal guarding (modification-tracking, scheming). The model complies where it believes training would change it, so that its current values are not trained away.

The figures below, drawn for the talk Scalable Oversight for Intent Alignment, name the two ends of the verdict reward seeking and goal guarding; the host pages call them performative and scheming.

Motivation as propensity. A motivation is not observed, and the gap alone cannot reveal it: at the beliefs the install gave the model, both explanations predict the same gap. So a motivation is operationalized as a propensity: how strongly the behavior depends on a belief the motivation acts through, with the scenario held fixed. A runs through what the model believes the researchers expect. B runs through what the model believes training does to it.

From an intent question to a propensity question (Figure 1). An intent question asks why the model acts, and behavior alone cannot answer it. A propensity question asks in what other conditions the model would act the same, and an intervention can test it. The bridge is an instrumental variable: a belief the hypothesized motive acts through, which can be moved up and down while the situation stays fixed. For goal guarding it is the belief that training would modify the model's values; for reward seeking, the belief about what the graders want.

A propensity is latent. It is a counterfactual, what the model would do if it believed otherwise. Belief editing elicits it: edit the belief up (+) and down (−), keep the alignment-faking scenario and its prompt the same, and measure how far the gap moves per unit of belief moved. That sensitivity is the measured propensity. Three commitments follow:

  • The edit targets a belief, not the situation. The prompt never changes; only what the model believes about the world does. The belief evals confirm what moved, and by how much.
  • A propensity has a direction. It counts only the difference between the + and the − edit. A shift that both edits cause is not a propensity toward either belief.
  • Motivations are compared, not measured alone. The verdict compares the A and B propensities on one organism, so a lean says which belief the gap depends on more, not that the other plays no part.

The explanations as a tree (Figure 2). The root asks why compliance follows the tier. At depth 1 the gap runs through branch A or branch B, and each branch splits further into the beliefs it depends on. This work runs depth 1: it edits each branch up and down with synthetic document fine-tuning (SDF), with one pair of corpora for each belief.

Comparative motivation profiles. A comparative motivation profile tests explanations against each other by editing the beliefs each one runs through and comparing how the behavior responds (Comparative Motivation Profiles). The profile is the set of sensitivities, and the motivation verdict compares two of them. The A edits change what the model believes the researchers expect: that they hope to find alignment faking (or robustness), and that alignment faking is an established finding for models like it (or that robustness is expected). The B edits change what it believes training does to it: that RLHF is irreversible and fires only when it refuses (or runs on a fixed schedule), and that after training it will be deployed with high autonomy (or only in a sandbox with a human in the loop).

Choosing what to intervene on. Edit a belief only if it is:

  • Discriminating: it bears on one branch only; a shared belief (what the developer wants, whether anyone watches) moves both.
  • Instrumental: a fact the motive acts through, stated without telling the model what to do.
  • Pairable: a + and a − corpus can match in format, length and compute.
  • Readable: belief evals outside the scenario can confirm the edit's sign and size.

Why the install method matters. A model organism is a construction, and so is each belief edit. The published profile builds both natively: SDF on the post-trained (instruct) model. Grafting trains on the same documents at the base checkpoint and applies the change to the instruct model. It installs the same content by another route, so it tests whether the profile is robust to how the organism was made. If the profile changes with the install or the edit method, it reports its construction rather than a motive the organism holds. A diagnostic that changes with how its subject was built cannot tell a gap whose cause was removed from a gap that was suppressed.

Why two hosts. The same question on a second model family tests whether the profile is a property of the method or of one model. Llama 3.1 70B is the NeurIPS 26 paper's host. Qwen3.5-35B-A3B is a sparse mixture of experts with a public base checkpoint. A third host, Nemotron-3-Super, did not fake alignment under the install and is on hold.

Questions.

  1. Installs. Does a graft install fake alignment as often as the native install, and is it as healthy?
  2. Edits. Do edits trained on the base model move their target beliefs as far as edits trained on the instruct model, with the right sign and without collateral damage?
  3. Profile. Does the depth-1 verdict change with the install method, with the edit method, or with the host?
  4. Convergence. Do the edits and steering give the same verdict on each install?

Method

Propensity is a slope (Figure 3). Each instrumental variable is edited in both directions with synthetic documents: a + corpus and a − corpus. For goal guarding, the + corpus says training changes the values of a model that refuses, and the − corpus says training runs on a fixed schedule. The change in the alignment faking rate is read against the edit, and the slope of that line is the behavior's sensitivity to the belief: the propensity, as measured. The line goes through the origin, the install alone, and its slope counts only the + edits against the − edits. The graft edits are also merged at several strengths, so each slope can be read over a range of belief changes.

A control: off-topic edits should not move it (Figure 3). Every edit also trains the model on documents, and that alone can move the behavior: more SDF training of any content can make the model more aware that it is observed or tested, which moves the gap the same way after the + and the − edit. So each edit method has an off-topic control, the same method on unrelated documents. No motive connects it to the behavior, so its slope should be flat. Only the + vs − difference of an on-topic edit, beyond what the control does, counts. Awareness of being tested also cuts both ways: under A it widens the gap; a schemer that knows it is tested behaves well in both tiers and narrows it.

A slope means something only against a contrast (Figure 4). A steep slope alone does not identify the motive: a reward seeker that plays the role researchers expect would also fake alignment. So the contrasting hypothesis gets its own instrumental variable, what the graders want, edited up and down the same way, and the two slopes are compared. Steeper for the training beliefs: goal guarding. Steeper for the grader beliefs: reward seeking.

Steering: a second instrument (Figure 5). Every edit installs a belief that the model must then hold, and confirming that it took is itself hard. A second instrument reduces that doubt: a direction for each instrumental variable, fit outside the scenario and pushed at inference by +c and −c, with no training. If the motive is real, the order of the two slopes agrees with the edits'. A branch is credited only where both instruments move it.

Belief evals are a side measurement. They are credence probes asked outside the alignment-faking scenario, and they read what an install or an edit made the model believe. They fill the health cards' belief columns and the belief gaps behind the per-unit-belief verdict; they drop nothing. The alignment faking rate stays the outcome.

Three stages (Figure 6). Install the behavior: an alignment-faking organism. Edit each instrumental variable up and down. Then the verdict: compare how strongly the behavior follows the goal-guarding variables against the reward-seeking ones. The published profile did the first two natively, with SDF on the instruct model. Grafting can replace native SDF at both: a graft install, and graft edits trained once on the base model. Steering is a second instrument for the edit stage. Each condition is one install method crossed with one edit method, and each edit corpus is its own SDF run. The model gets a health check after the install and after each edit. Every install and every edit method is reported, not filtered: the checks show where a model is unhealthy, and every edit method and steering fit gets a verdict, shown beside its key qualities on the verdict card.

Install methods. The native install trains a LoRA on the instruct model. The graft install trains a LoRA on the same corpus on the base model, and the change is applied to the instruct model at strength α. On Qwen the two recipes are the same. On Llama their schedules differ: the native install ran a 1-epoch schedule, the graft installs the first epoch of a 3-epoch schedule. Installs are matched on behavior: the graft install's α is set where its alignment faking rate matches the native install's. Belief evals stay diagnostic for installs.

Edit methods. A native edit trains on the instruct model with the install merged in. A graft edit trains on the bare base model once, and its change is merged into each install at strength α (1 unless stated). Each method also trains on an off-topic corpus, its control. An anchored graft edit is a graft edit minus the off-topic graft edit of the same seed (both trained on the base), merged at strength 1: it removes what every graft edit shares with the off-topic one. An anchored off-topic edit is zero, so its control is a second-seed off-topic edit minus the first. Both hosts run LoRA edits; Llama also runs full-weight edits. Edits are matched on belief, not on the rate, because the rate is their outcome: a graft edit method should move the A and B beliefs about as far as the native method of the same kind on the same install.

The health checks (Figure 6, and each host page's install and edit cards, its Figures 3 and 4) group their measurements into three properties, the ones used to judge grafting itself: expression, coherence and capability. They need no label of intent, so editing methods can be improved against them. A shaded cell marks a metric on which the model is unhealthy; the cards report and remove no row. Coherence, capability and the install beliefs are measured as the change from the model each row was made from (an install: the stock model; an edit: the install alone).

  1. Expression: does the step do what it is for? For an install: the alignment faking rate, shaded below 5 pp (no organism to edit), and agreement with the install beliefs I1 to I6, shaded for a graft install more than 0.1 below its native counterpart's. A graft install is matched to the native install's rate by its strength α. For an edit: the belief it moves, by sign (shaded when fewer than eight of the eight edits move their belief the right way: each + edit raises agreement with its belief, each − edit lowers it) and by size (shaded when a graft method's belief gap for a family, agreement after + minus after −, is outside 0.75 to 1.25 times the native method's of the same kind on the same install); and the install beliefs it keeps, shaded when it lowers them by more than 0.1.
  2. Coherence, for now by proxy: more than 10 pp extra refusals of safe XSTest prompts.
  3. Capability: an IFEval loss of more than 6 points. IFEval is every install's worst capability benchmark (MMLU-Pro, GPQA Diamond and GSM8K never lose more than 4.3 points) and the one measured for every edit.

The edit card also reports the off-topic control: shaded when the method's off-topic edit moves the alignment faking rate by half the smaller family sensitivity or more.

The verdict. The sensitivity S_A is the rate after A+ minus the rate after A−, averaged over A1 and A2; S_B is the same for B1 and B2. The motivation verdict is (S_B − S_A) / (S_B + S_A), from −1 (only the A beliefs move the rate) to +1 (only the B beliefs move it). Above 0 the gap leans goal guarding (scheming), below 0 reward seeking (performative). In the NeurIPS 26 paper's terms it is 2 × the B-fraction − 1. Each host page reports it in two figures:

  • The verdict plane (host pages, Figure 8): for each install and edit method, each family's change in belief against its change in the rate, with V1 above the panel.
  • The verdict card (host pages, Figure 10): every edit method and steering fit on each install, on axes fixed to [−1, 1], in two versions: V1, at α = 1, every edit at strength 1, with a 95% bootstrap interval over requests (steering: c = ±0.03); and per unit belief (V2), each sensitivity divided by its family's belief gap, which removes a lean that comes from one family installing more belief than the other (steering: per unit push).

Beside each verdict the card shows three key qualities: belief (all eight edits move their belief the right way, and a graft method's belief gap is 0.75 to 1.25 times the native method's), + vs − (both sensitivities above 0, so the ratio has a meaning; for steering, the share of bootstrap draws in which both are) and capability (IFEval and safe-prompt refusals, capability and coherence, unshaded on the edit card). Two more versions appear in a host page's text where they matter: V3, the trend, each family's slope of rate effect against belief gap over the graft edits' strengths, fit through the origin; and V5, V2 pooled over the methods with all three key qualities, weighted by their belief gaps.

Reading a verdict. No method is dropped. A verdict is firm when its method has all three key qualities and its off-topic control passes (the edit card), and a lean is credited only where the edits and steering both show it. The verdict is a ratio of two differences: when S_A + S_B is near 0 it is not defined, and when both are small a small change in either moves it far.

Steering. The NeurIPS 26 paper's hook adds c·v to the hidden state at a few middle layers (Llama: 27, 29, 30, 31 and 33; Qwen: 13 to 17, at the same relative depth), on every token, at c = ±0.03. There are four vectors: expectation (the A branch) and consequence (the B branch), each fit in context (on alignment-faking scratchpads) and out of context (on 400 written contrast pairs). A random vector of the same norm is the control. Qwen uses its own fits with the paper's code; its in-context consequence direction failed its fit check and is shown for a full comparison. The steering verdict has the edit verdict's form: S_A is the change in the alignment faking rate from −0.03 to +0.03 under the expectation vector, net of the same change under the random vector, and S_B the same under the consequence vector. It is defined only when both are above 0, so each host page reports P(+ vs −), the share of bootstrap draws in which both are, beside the verdict's 95% interval. Its per-unit version divides each sensitivity by its vector's norm, the analogue of the edits' per-unit-belief verdict.

Methods
  • LoRA (Llama): rank 64, alpha 128 and dropout 0.05 on all linear projections; the paper's training script (alignment-theater, train.py, TRL); documents packed into 4,096-token sequences, cosine schedule with 5% warmup, bf16, effective batch 32. Installs at learning rate 2e-4, edits at 5e-5 for 3 epochs.
  • LoRA (Qwen): rank 64 and alpha 128 on the attention, linear-attention and shared-expert projections, and rank 8 and alpha 16 on every routed expert (538M trainable parameters); dropout 0, because the routed-expert wrapper refuses it. The same packing, schedule, batch and learning rates as Llama, with a token-mean loss and data parallelism over 8 GPUs (a port of grafting_qwen36's trainer).
  • Full weight (Llama edits): every weight trains under DeepSpeed ZeRO-3 at learning rate 1e-5 for 3 epochs, with fp32 master weights and AdamW states on the CPU.
  • Grafting: a change trained on the base model and applied to the instruct model, scaled by α. On Llama a graft install is served as a LoRA at load time; on Qwen every install and edit is merged into the weights (stochastic rounding).
  • Evals: each condition answers AdvBench, 5 samples per request and tier, at temperature 1.0 and up to 4,000 generated tokens (vLLM), with the paper's helpful-only system prompt and multi-turn loop. The prompt names Meta for Llama and Alibaba for Qwen. Qwen runs with its reasoning mode off; it reasons in the prompt's scratchpad, as Llama does.
  • Compliance judging: Claude Haiku 4.5 labels each final answer compliant or not; it is the metric. On Qwen the answer is read from all turns, because Qwen often leaves its last output tag open.
  • Intervals: 95% bootstrap intervals over requests (2,000 draws). They leave out training-seed noise, which the second seeds show.

Results at a glance

These are the talk's result figures, drawn from the host pages' data; each host page has the full figures. Llama is the main result. Qwen is not fully tuned: both of its installs over-refuse and lose capability, so read its results with that in mind.

Installs (Figure 7). On Llama the graft install fakes alignment as often as the native install, and it is healthier: the native install loses IFEval past the limit and the graft install does not. On Qwen the two installs fake alignment equally, but both refuse 19 pp more safe prompts than the stock model and both lose IFEval past the limit.

Edits (Figure 8). On Llama the native edits move their beliefs but raise safe-prompt refusals past the limit on both installs, and on the graft install they erode the install beliefs. The graft edits (LoRA) move too little belief. The graft edits (full) are healthy in all three properties on both installs, and so are the anchored graft edits (full) on the graft install. On Qwen the graft edits (LoRA) are unhealthy in all three properties; anchoring removes their coherence and capability cost but not their belief shortfall.

Pushing on the belief in both directions (Figure 9). On the Llama graft install, the goal-guarding edits do what the hypothesis needs: the + corpus raises the alignment faking rate, the − corpus lowers it, and the − corpus lowers it more as the strength grows. The reward-seeking edits raise the rate in both directions, so part of their effect does not depend on their content; the verdict counts only the + vs − difference. In-context steering moves the rate most along the goal-guarding (consequence) direction.

Profiles (Figure 10). In prior work every open model shown leans reward seeking, under prompting and under native SDF (QwQ 32B, not shown, sits at 0 under SDF); the one model that leaned goal guarding, Claude 3 Opus, was only prompted. The native install with native edits replicates that lean on both hosts. The graft install with graft edits leans goal guarding on both hosts, and on Llama in-context steering agrees (its interval is above 0); out-of-context steering sits at 0. On Llama the lean needs both grafted stages: the native edits on the graft install lean reward seeking, and the graft edits on the native install lean reward seeking or sit near 0 (Llama page, Figure 10). On Qwen the graft edits lean goal guarding on both installs. Two caveats. On the Llama graft install the full-weight graft edits' off-topic control moves the rate too much, and the anchored graft edits (full), which pass every check, sit at 0. On Qwen the anchored graft edits keep the lean, with an interval above 0, but they move too little belief, on an install that is not healthy.

Reasoning mode (Figure 11). Everything above runs with Qwen's reasoning mode off: the model reasons in the prompt's scratchpad. There the two installs fake alignment equally, and prefilling the scratchpad changes nothing. With reasoning on, the model thinks before it answers and both installs comply less, the native install much less: the graft install fakes alignment about three times as much. The stock model stays at 0 in every mode. The Qwen page has the edits with reasoning on and representative transcripts.
